## 结论

判定：**流畅** = 不限帧率时 ≥ 60 FPS；**可用** = ≥ 30 FPS；两者都要求数据不积压（显示滞后 < 0.1 秒）且 UI 延迟 p95 < 50 ms。

- 1100×660：流畅（≥ 60 FPS）最多 **50** 条，可用（≥ 30 FPS）最多 **150** 条（实测档位：10 / 25 / 50 / 100 / 150 / 200 / 300 / 400 / 500）。
- 1920×1080：流畅（≥ 60 FPS）最多 **25** 条，可用（≥ 30 FPS）最多 **50** 条（实测档位：10 / 25 / 50 / 100 / 150 / 200 / 300 / 400 / 500）。
- 1100×660 帧率上限 30：稳定 30 帧、数据不积压、UI 不卡，最多 **150** 条（UI 线程占用见第 2 节，留出余量时建议不超过占用约 70% 的档位）。
- 所有档位都没有丢点：写入 100% 达成，积压不超过 0.2 秒——瓶颈是绘制（每帧耗时随曲线数线性增长），不是数据接收。
