## P0

### 1. 后台 `AddSeries` 与 UI 线程遍历 `_series` 竞争
- **现象**：后台线程调用 `AddSeries` 时，UI 线程的 `AddValue` / 合并写入可能抛 `InvalidOperationException`（Collection was modified）；若发生在合并写入回调里就是未处理 UI 异常（违背"不能闪退"）。
- **原因**：`CreateSeries` 直接在调用线程执行 `_series.Add`；`VisibleExtents`、`FlushPendingValues`、`RefreshXMapping`、`EnsureAbsoluteStartTimes` 遍历时不持锁。
- **改法**：后台 `AddSeries` 不直接改 `_series`（只放入 `_pendingAttach`，由 UI 线程加入并挂接）；或读取方改用写时复制的快照数组。
- **验收**：后台 `AddSeries` 与 UI 线程写入/渲染并发跑 1 分钟，无异常；补回归测试。

## P1

### 2. 空曲线/全缺失曲线让自动缩放产生非法 Y 轴
- **现象**：一条正常曲线 + 一条空曲线（或全 NaN），右键菜单"自动缩放"后 `Y=[-∞, ∞]`；新建空控件同样。之后渲染会变成 `±11.5` 之类，只有再写一个点/重选模式才恢复。
- **原因**：`GetLimitsY` 对无有效数据的区间返回 `±∞`；`HandleAutoscaleRequested` 因 `ReadLimits()` 返回 null 直接 return。
- **改法**：无有效数据时返回"无范围"（NaN 或 `AxisLimits.NoLimits`）；自动缩放不依赖 `ReadLimits()` 成功，直接走重算分支。
- **验收**：存在空曲线时，菜单 / 中键 / A 键整体显示后 Y 有限且符合需求 1。

### 3. `PlotSeries.Clear()` 后解除 Y 锁
- **现象**：Y 被拖动锁定后清空唯一曲线，再写入不同量级的数据，曲线整条落在视图外；`ResetYAxis()` 才恢复。
- **改法**：清空后若没有可见数据（`VisibleExtents` 为空）就解除 Y 锁；或 `ClearSeries` 一律解除。
- **验收**：清空唯一曲线 → 写新量级数据 → Y 自动适配。

## P2

### 4. 堆叠百分比在无数据/清空后设置无效
- **现象**：无数据时设 50%（或 `ClearData()` 后）再写数据，X 仍为 `[0, 点数+2]`。
- **改法**：空数据时标记"原点未固定"，首批数据到达时按百分比补算一次；或文档写明必须在有数据后设置。

### 5. 每曲线 `YScale/YOffset` 与自动 Y 不兼容
- **现象**：`Signal.Data.YScale = 100` 时曲线放大 100 倍，但自动 Y 仍按原始值，曲线被裁掉。
- **改法**：Y 范围统计计入 `YScale/YOffset`，或提供 `PlotSeries.Gain/Offset` 并统一渲染与坐标轴。

### 6. `AxisUpdateMode.Auto` 的 8 条阈值
- **现象**：8 条可见曲线逐点约 3.2 µs/点，9 条（合并）约 0.17 µs/点；默认阈值把最坏情况留在 8 条。
- **改法**：默认阈值降到 2~4，或按写入速率自适应；改动前确认"写入后立即读坐标轴"的兼容性（`UpdateAxesNow()` 兜底）。

### 7. 缓冲区倍增卡顿与无界内存（原 Q6）
- **现象**：单曲线 16.4M 点一次扩容 42 ms、32.8M 点 92 ms；33M 点托管堆约 800 MB；缺失区间列表约 8 B/区间。
- **改法**：按 Q6 的分段存储（固定块）+ 冷热数据方案落地；过渡期可先提供 `EnsureCapacity` / 保留点数上限。
